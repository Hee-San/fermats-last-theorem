3. Frey 曲線の mod p 表現の既約性

theorem FreyPackage.Mazur_Frey (P : FreyPackage) : GaloisRepIsIrreducible (K := AlgebraicClosure ℚ) ℚ P.freyCurve P.p

GaloisRepIsIrreducible（Definitions/Def_FLTPrelim_GaloisRep.lean）は基底によらない定式化です。EP​(Q​) の p ねじれが非自明で、その Galois 安定な Z/p 部分加群が 0 と全体だけであること。証明モジュールはまず a≡3(mod8) の場合を切り分けます。この場合には素数 2 における独自の議論があります（FreyPackage.Mazur_Frey_of_a_mod_eight）。それ以外の場合は背理法で進めます。可約な EP​[p] は、商への Galois 作用が自明な Galois 安定直線 — 余固定直線（cofixed line）、HasGaloisStableCofixedLine（Definitions/Def_FLTPrelim_CofixedLine.lean）— をもちます。これは FreyPackage.frey_reducible_hasCofixedLine による（EP​[p] の安定直線は固定または余固定である、という Serre の観察。EP​[p] が 2p の外で不分岐であることと、EP​ が位数 p の有理点をもたないことを使います）。そして余固定直線は p の三つの範囲で別々に除外されます。

  • p≥17 — FreyPackage.frey_no_cofixed_large。これは Mazur の Eisenstein イデアルの議論で、このステップの中で群を抜いて大きな部分です。約 5,400 個の定理がその下位にあり、そのうち約 2,400 個は ModularCurve 名前空間にあります。1,400 行の証明モジュールは 43 個の定理を引用します。abc を割るすべての素数における整 Frey モデルの乗法的還元。乗法的素数と p における、単位元成分の上と外にあるねじれ点の局所解析（WeierstrassCurve.InZeroComponentAt、Definitions/Def_EllipticCurve_ZeroComponentAt.lean）。Frobenius 元とねじれ表現の行列式。そして唯一の大域的な入力 WeierstrassCurve.mazurStepThree_not_inZeroComponentAt（Mazur の「Step 3」：素数位数 p∈/{2,3,5,7,13} の有理点が 2 と 3 において単位元成分の外にあれば、他のすべての乗法的素数 ℓ=p においても単位元成分の外にある）。その下には X0​(N)、その Jacobian、カスプ部分群、Eisenstein 商（ModularCurve.eisensteinQuotientInvariantsFiniteAt_heckeModuleBar、ModularCurve.mazurQuotientSpecialization_heckeModuleBar、…）があり、ModularCurve、AlgebraicGeometry、AlgebraicCurve の名前空間で展開されています。
  • p=11 — FreyPackage.frey_no_cofixed_eleven、および p∈{5,7,13} — FreyPackage.frey_no_cofixed_small。これらは楕円曲線に関する議論ではありません。それぞれ、その指数に対するフェルマーの最終定理を直接証明すること（fermatLastTheoremFive、…Seven、…Eleven、…Thirteen。いずれも型は FermatLastTheoremFor n）によって片づけられます。その p をもつ Frey パッケージは存在しないので、結論は空虚に成り立ちます。
  • fermatLastTheoremFive は Z[21+5​​] における自己完結した 2,000 行の降下法で、引用は Mathlib のみです。
  • fermatLastTheoremSeven、…Eleven、…Thirteen はそれぞれ、正則素数に対する Kummer の定理 flt_regular {p : ℕ} [Fact p.Prime] (hreg : p.Coprime (Fintype.card (ClassGroup (𝓞 (CyclotomicField p ℚ))))) (hodd : p ≠ 2) : FermatLastTheoremFor p（Theorems/Thm_flt_regular.lean。証明モジュール P2M/Sol/S_flt_regular.lean は Mathlib だけを引用する約 4,200 行で、flt-regular プロジェクトの移植 — 第一の場合、第二の場合、Hilbert の定理 90–94 を経由する Kummer の補題）と、第 p 円分体の整数環が単項イデアル整域であることの証明 IsCyclotomicExtension.Rat.seven_pid、….eleven_pid、….thirteen_pid（最後のものは約 730 行）を組み合わせます。
